# CLAUDE.md — standing rules for this repo

This is the **downstream serving mirror** for `files.cagd.as`, deployed via GitHub Pages out of `docs/`.
It is NOT where the source lives — the source of truth is the monorepo
[`cagdasunal/webflow`](https://github.com/cagdasunal/webflow) (`sites/cagdas/`). Read [`README.md`](README.md)
for the full bundle/vendor/data map; this file is the short "don't break it" list.

## Three rules that must never drift

1. **This is a build-output mirror — edit upstream, never here.** Do NOT hand-edit `docs/scripts/*`.
   First-party bundles (`audio-player.min.js`, `rates.min.js`) are build output: change the source in the
   monorepo (`sites/cagdas/scripts/src/`) and rebuild with `scripts/site_deploy.py`. Vendored libs
   (`gsap.min.js`) are pinned upstream distributions: replace them from their monorepo SSOT
   (`sites/cagdas/scripts/vendor/`), never run them through the build. A hand-edit here is silently
   overwritten by the next deploy.

2. **`docs/data/rates.json` and `docs/llms.txt` are bot-owned — never hand-edit.** They are regenerated by
   cron: `update-rates.yml` (daily) → `scripts/fetch-rates.mjs`, and `update-llms.yml` (every 12h) →
   `scripts/generate-llms.mjs`. Each workflow commits only when the content changes. Editing them by hand
   just gets reverted on the next run.

3. **`docs/` deploys live to `files.cagd.as`.** Everything under `docs/` is published by GitHub Pages
   (the `CNAME` is `files.cagd.as`). Treat any change under `docs/` as a production change — confirm before
   committing one.

## Validating the generators without writing

Both cron scripts support a non-writing `--dry-run` that prints to stdout instead of touching disk — use it
to inspect output safely:

```
node scripts/fetch-rates.mjs --dry-run        # prints rates JSON, writes nothing
node scripts/generate-llms.mjs --dry-run      # prints llms.txt to stdout, writes nothing
```

If you need to change what these produce, change the script + workflow in the monorepo SSOT
(`sites/cagdas/cron/`), not the generated file here.
